Generated by npm run signals from agent/agent.clean.js. One row per wire signal id. codes are the s values the collector and everything it reaches can return; APIs are the browser surfaces it touches, rarest-first; probes are the string literals in its own body and its direct helpers, which is where the names behind a computed lookup end up.

Stage request means the id is contributed by the module's toRequest, not by a sources stage — those ids ride the wire like any other but are collected as the payload is assembled.

v is the shape of the reported value where it is a literal in the source: object keys for an object, a kind otherwise, call where it comes back from a helper. hashed means the collector or one of its direct helpers reaches the x64-128 mixer, so what rides the wire is a digest and has to be reproduced rather than edited.

A few collectors read no browser surface at all: what they measure is the engine, and their APIs column carries that instead — a Math.random sequence, the byte order of a NaN in a Float32Array, whether Error.stack is populated.
