# Endpoints

Generated by `npm run endpoints`. The path rule is read from `agent/agent.clean.js`; the
sequence is whatever a `tools/spy.mjs` capture recorded, so it is one observed run and not a
specification.

## Path construction

`buildRequestPath` cuts a token into `/`-joined chunks. Each chunk length comes from
`fn60(arg731[v849&15], 4, 7)` — a byte of the seed, not a random
source, so lengths run 4 to 7 and the same token always yields the same path.
