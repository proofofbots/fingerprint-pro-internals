A failed signal is reported by throwing botdError(code, message), which the {s, v} wrapper turns into the status. Those throws are the only place the meaning of a code is written down, so the messages below are the agent's own words, not an interpretation. returned sites build the object directly, caught ones do it in a catch, and a fallback after Nms is a deadline handed to an internal helper.
